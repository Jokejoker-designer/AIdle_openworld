# AIdle Openworld Blueprint v1.1

This is the active Single Source of Truth. Version 1.0 is preserved as the
original concept baseline; contradictions are resolved by this package.

## North star

The player speaks, the Companion turns intent into a safe world proposal, the
world previews the change as light, and only a validated, confirmed transaction
becomes persistent reality.

## MVP truth

The first product is one playable **2.5D Private Reality** vertical slice. “Infinite
metaverse”, real cities, space travel and free-form Text-to-3D remain roadmap
horizons until the core prompt-to-world loop passes executable gates.
