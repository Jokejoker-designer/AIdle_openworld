# Development Roadmap — 2.5D first

## G0 Foundation

Complete contracts, architecture lock, design contract, Git baseline, project
room and automated document/schema validation.

## G1 Contract lock

World Prompt validator with at least 10 accepted and 10 rejected fixtures;
authority, event and version migration tests.

## G2 2.5D Godot shell

Pinned Godot 4 version, fixed-angle camera, player movement, layered tile/grid
world, occlusion handling, debug overlay and style-profile loader.

## G3 Manifestation vertical slice

Prompt form -> valid proposal -> house hologram -> confirmation -> progressive
materialization -> collision/navigation activation -> cancel and undo.

## G4 Persistence

Save/reload produces the same entities and provenance; duplicate request is
idempotent; revision conflict is visible and recoverable.

## G5 Companion

Conversation, intent proposal, inspectable memory, emotion expression and tool
allowlist. Add bounded Base/Adaptive Traits, slow-drift receipts, lock/reset/delete
controls. The MVP is text-only; Companion cannot commit directly.

## G6 Two-client authority

Two clients observe one server-approved manifestation; forged client mutations
are rejected. This gate chooses/confirms Nakama.

## G7 Art and performance

Style conformance, accessibility, stable camera readability and measured budgets
on the target device. Generated assets remain async and optional.

## G8 Alpha gate

End-to-end 2.5D vertical slice, independent Purple report and Human acceptance.

Post-alpha only: voxel terrain, real-city hubs, marketplace money, spacecraft,
exoplanets, TTS/voice, neural world-model portals and unrestricted Text-to-3D.
