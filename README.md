# AIdle Openworld

AIdle Openworld is an AI-native creative open world. The active specification is
`AIdle_Openworld_Blueprint_v1.1/`; `AIdle_Openworld_Blueprint_v1.0/` is retained
as the immutable concept baseline.

Start with `AGENTS.md`, then `AIdle_Openworld_Blueprint_v1.1/00_README.md`.

The active Godot scaffold is `game/`. `AIdle_Openworld_Prototype/` is a
legacy experimental artifact generated in parallel from Blueprint v1.0; it is
not the source of truth and must not be merged into `game/` without an
acceptance review. The local `aidlaedemo/` folder is external/untracked output.
