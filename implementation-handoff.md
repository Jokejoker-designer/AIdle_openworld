# First visual implementation handoff

Read `DESIGN.md`, `design-contract.md`, `orchestration/ARCHITECTURE_LOCK.md` and
the v1.1 Progressive Construction spec. Build only a 2.5D Private Reality scene:
fixed three-quarter camera, one player, one Companion, one empty plot and one
modular small house. Prove pending hologram, confirmation, 8–15 second staged
materialization, collision activation, cancel and undo. Do not add multiplayer,
voxel digging, marketplace, city, spacecraft or generative mesh dependencies.
Use text-only Companion interaction; do not add TTS, microphone or voice models.
