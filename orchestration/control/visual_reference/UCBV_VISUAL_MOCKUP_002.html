New findings this pass — logged, not silently resolved

  • Two "cozy cream" palettes exist. COZY_ART_BIBLE_001.md (architecture, approved, live in game) uses wall cream #fdf3e2 / foliage #7fc98f. The DNA package's own mat_cozy_cream_leaf_v1 (used by the actual character recipes) uses cream #F7E9C6 / leaf #78B65B. Close, not identical, never reconciled. This sheet uses the art bible for architecture/nature and the recipe palette for characters, matching what each source file actually specifies — it does not invent a merged colour.
  • Manifestation stage count disagrees. The village build graph declares 5 stages (adds COMMITTING between materializing and complete); the art bible and the live, verified game implement 4.
  • Skeleton catalog has the same "shared default" gap as the block catalog. All 14 skeleton families store identical placeholder required_bones and attachment_sockets — only names, bone counts and animation-set links are individualized.
  • Character Foundry prose rig names don't map 1:1 to catalog skeleton ids. "Humanoid-small-01" and "Humanoid-stocky-01" appear only as descriptive text in the 28-record Character Foundry package; the DNA catalog has one generic skel_stylized_humanoid_v1 and one heavy golem skeleton. Section 8 proposes mappings; it does not resolve which is correct, and Bác Bắp's is left as an explicit open question with two named options.
