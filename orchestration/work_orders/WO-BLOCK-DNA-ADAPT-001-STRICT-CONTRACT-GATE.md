## Required fail-closed semantics

- Typed nested Build Recipe and Build Graph entries; unknown fields rejected.
- Non-empty finite bounds; numeric coordinates reject booleans, NaN and Infinity.
- `expected_world_revision` is an integer with minimum zero.
- Idempotency key binds a canonical validated payload fingerprint. Identical
  replay is stable; changed payload with the same key is a conflict.
- Node IDs and edge IDs are unique; every reference resolves.
- Sockets carry explicit input/output polarity; connections require opposite
  polarity and declared mutual compatibility in both directions.
- The four known asymmetric source relations must fail the source audit unless
  normalized explicitly in the adapter contract without rewriting the source:
  `terrain_surface/prop_base`, `building_foundation/vertical_stack`,
  `wall_edge/window_opening`, `wall_edge/door_opening`.
- Occupancy, collision bounds, transform, grid/elevation snap, rotation snap,
  maximum scale delta and cycle policy are deterministic and fail closed.
- Seeds are required and bounded for procedural content. Generator, behavior,
  world-rule and module IDs are allowlisted catalog references, never code.
- Semantic material slots map explicitly to active P1E-006 imported material
  resources; no parallel style-variant system may be invented.
- Adapter output is a proposal satisfying the active Structured World Prompt
  contract. It cannot confirm, commit, mutate ownership/economy/inventory,
  execute arbitrary code or bypass preview/World Commit.
- Missing modules produce a typed Asset Request proposal, never executable code.

## Mandatory invalid cases

Include at least: `nodes:[42,null]`; malformed/unknown edge; empty or inverted
bounds; negative revision; bool/NaN/Infinity numeric values; duplicate IDs;
dangling reference; same-polarity socket; one-way/asymmetric compatibility;
double occupancy; bounds escape; off-grid transform; invalid elevation;
off-snap rotation; forbidden cycle; missing/non-deterministic seed; unknown
generator/behavior/world rule/module; material-slot mismatch; direct-commit or
authority-shaped fields; stale revision; changed-payload same-idempotency key.
