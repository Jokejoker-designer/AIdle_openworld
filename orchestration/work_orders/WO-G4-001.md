# Work Order — G4-001 Deterministic Save, Reload and Compensation

Authority: `PATCH_DRAFT` only for `persist`; all other agents `VERIFY_ONLY`.
Final acceptor: Codex.
Parent: the existing Grok Desktop conductor session only.

## Scope and authority

Implement deterministic persistence for the local/offline **Private Reality
simulation**. Do not claim canonical Shared District, economy or ownership
authority. Those remain server-authoritative and outside this work order.

## Mandatory installed-subagent workflow

1. `schema` defines canonical serialization, stable entity-hash and journal
   invariants without product writes.
2. `persist` is the sole product writer for persistence, journal, compensation
   and tests.
3. `executor` verifies G3 complete/cancel/undo receipts are consumed without
   bypassing World Commit authority.
4. `core` independently verifies save → reload integration and clean Godot boot.
5. `network` performs Purple authority/idempotency review.

The parent only dispatches and collates evidence. One writer per file; no
nested grandchildren or other profiles.

## Required behavior

- Canonical, deterministic serialization with stable ordering and explicit
  schema version.
- Save and reload produce identical entity hashes for the same state.
- Replaying the same request/idempotency key never creates a duplicate entity.
- A stale expected revision is rejected without partial state mutation.
- Compensation is a new append-only operation linked to its prior receipt; it
  never deletes or rewrites history.
- Cancelled previews never enter durable local save state.
- Truncated/malformed journal or incompatible schema fails closed with a clear
  recovery error; do not silently invent state.
- G3 `expected_world_revision=3` remains preserved through save/reload evidence.

- Duplicate request replay test proving no duplicate entity.
- Stale revision and malformed/truncated journal negative tests.
- Compensation receipt and append-only history proof.
- Clean integrated Godot log and `AIDLE_VALIDATION=PASS`.
- Valid MAF receipt per subagent, ownership map and Purple review.
