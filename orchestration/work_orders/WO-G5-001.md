## Gateway requirements

- Provider-neutral interface. No provider is selected or called in this work
  order; use only a deterministic fixture provider for local tests.
- Gateway validates and redacts the incoming World State Snapshot before any
  provider call and validates the outgoing AGM Decision Envelope before return.
- Response remains an untrusted proposal; it cannot bypass consent, executor,
  preview or World Commit.
- Server-side credential provider boundary only. No API key, client secret,
  bearer token or provider SDK in Godot, committed fixtures, logs or receipts.
- Deny outbound calls by default. Provider/domain allowlisting and real network
  enablement remain HITL.
- Request/idempotency IDs, bounded timeouts and retries, deterministic retry
  policy tests, and no retry on validation/policy/auth failures.
- Compute budget estimate, hard per-request cap and session cap. Reject before
  provider dispatch if the cap would be exceeded; no negative balance.
- Structured error envelope must distinguish validation, policy, budget,
  timeout, retry exhaustion and provider-unavailable failures without leaking
  secrets or raw hidden prompts.
- Free and Paid editions use identical Snapshot/Decision semantics.
