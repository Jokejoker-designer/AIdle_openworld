# Module Taxonomy

Các domain: geometry primitives, terrain chunks, paths/water, architecture, nature/biome, props/systems, characters, attachments, module clusters, gameplay behaviors, VFX/audio, world rules và procedural generators.

Ngoài nhà và nhân vật, block system có thể xây đường, cầu, ray, mạng nước/năng lượng, nông trại, workshop, đền, portal, puzzle, đảo nổi, căn cứ biển, phương tiện, social venue, quest area, seasonal states và HLOD chunks.
