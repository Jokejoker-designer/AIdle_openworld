# AIdle Block & Module Foundation v1.0

Gói nền tảng để AI xây thế giới bằng block, module, socket và Build Graph.

## Quy mô
- 170 modules
- 40 socket types
- 15 skeleton families
- 21 animation sets / 172 fixed clips
- 8 material themes có thể đổi màu
- 46 behavior blocks
- 38 procedural generators
- 16 VFX blocks, 14 audio blocks, 13 world rules
- 10 recipes/graphs mẫu

## Flow
Player prompt → Grok planner → registry search → Build Recipe/Graph → validator → Blender quarantine → Godot preview → confirm → World Commit.

Package ở trạng thái DESIGN_READY. Catalog/schema/validator được test; Godot/Blender scaffold cần chạy trong repo thật.
